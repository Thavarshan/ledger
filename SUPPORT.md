# Support

Use [GitHub Discussions](https://github.com/Thavarshan/ledger/discussions) for questions, setup help, and ideas. Use [GitHub Issues](https://github.com/Thavarshan/ledger/issues) for reproducible bugs and actionable feature requests.

Before opening a thread, search existing discussions and issues. Include your PHP, Node.js, database, and operating system versions when reporting setup or runtime problems.

Never share credentials, production environment variables, personal financial data, or database dumps in public support channels.
