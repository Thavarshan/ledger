# Security policy

## Supported versions

The `main` branch is the currently supported development line. Security fixes are evaluated against the latest released version and the current `main` branch.

## Reporting a vulnerability

Please use [GitHub Private Vulnerability Reporting](https://github.com/Thavarshan/ledger/security/advisories/new) when available. If private reporting is unavailable, contact the repository maintainers through the repository owner before disclosing details publicly.

Include the affected component, reproduction steps, impact assessment, and any proposed mitigation. Please do not include live credentials, personal financial data, or other secrets in a report.

We will acknowledge reports as soon as practical, investigate privately, and coordinate disclosure after a fix or mitigation is available.
